# Moo Moo 🐄
### Milk, Moo, and Magic! — Moo Your Way to Victory!

An exciting **3-lane endless runner** HTML5 game where you help Moo Moo the cow escape from a busy farm!

🎮 **[Play Now →](#)** *(link akan diupdate setelah deploy)*

---

## 🕹️ How to Play

**Keyboard (PC/Laptop)**
| Key | Action |
|-----|--------|
| `A` / `←` | Move left |
| `D` / `→` | Move right |
| `W` / `↑` / `Space` | Jump over fences & hay bales |
| `S` / `↓` | Slide under barriers |
| `P` / `Esc` | Pause |

**Touch (Mobile/iPad)**
- Swipe left/right to switch lanes
- Swipe up to jump
- Swipe down to slide

## 🌾 Biomes
| Zone | Distance | Theme |
|------|----------|-------|
| Barnyard Escape | 0–500m | Bright morning farm, wooden fences, hay bales |
| Harvest Fields | 500–1500m | Golden sunset, cornfields, tractors, mud |
| Country Highway | 1500m+ | Asphalt highway, trucks, helicopter boss |

## ⚡ Power-Ups
- 🥛 **Turbo Milk** — Invincibility + speed boost (5s)
- 🧲 **Coin Magnet** — Attracts all nearby coins (8s)
- 🛡️ **Milk Shield** — Absorbs one hit

## 👾 Enemies
- 👨‍🌾 **Farmer Joe** — Chases from behind, throws nets
- 🐕 **Rover the Dog** — Leaps into your lane
- 🚁 **Farm Helicopter** — Drops net barricades from above

## 🛠️ Tech Stack
- Pure HTML5 Canvas + JavaScript
- No frameworks, no build step
- Works on any modern browser

## 📦 Run Locally
```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/moomoo-game.git
cd moomoo-game

# Serve with any static server
python3 -m http.server 8080
# Open http://localhost:8080
```
